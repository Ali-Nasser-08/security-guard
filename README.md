# تدريب طويق

موقع عربي مخصص للهواتف لتدريب حراس الأمن على مطابقة الهويات مع كشوف تصاريح الدخول.

- هويات وكشوف مولّدة ببيانات تخيّلية، مع تكبير سهل للمستندات.
- قرارات السماح أو عدم السماح بالدخول، وإشعارات قصيرة عند الخطأ.
- حفظ التدريب الجاري والإحصاءات على الجهاز في سجل واحد.
- تقارير أداء قابلة للتصدير كصورة أو ملف PDF.
- تشغيل دون إنترنت بعد ظهور «جاهز دون اتصال».
- تدريب المركبات: قريباً.

تصميم وإعداد الأداة: **سامي ناصر الغامدي**.

## الاستضافة على Vercel

استورد هذا المستودع واضغط **Deploy**. ملف `vercel.json` يضبط الإعدادات تلقائياً:

- Framework: Other
- Build Command: `node tools/build.cjs`
- Output Directory: `dist`
- لا توجد حزم لتثبيتها، أو متغيرات بيئة، أو خدمات خارجية.

ملفات التشغيل فقط تُنسخ إلى `dist`؛ صور المراجع وملفات المعاينة والاختبارات لا تُنشر.

## التشغيل محلياً

يتطلب Node.js لتشغيل المعاينة فقط:

    node tools/preview-server.cjs

افتح http://127.0.0.1:4173/index.html. يمكن أيضاً فتح `index.html` مباشرة، لكن التخزين المؤقت دون اتصال يحتاج HTTPS أو localhost.

## الاختبارات

    node tests/training.cjs
    node tests/interface.cjs
    node tests/offline.cjs

الموقع مبني بـ HTML وCSS وJavaScript دون إطار عمل. بيانات المتدرّب تبقى في المتصفح؛ حذف بيانات الموقع يمسح الحفظ. ملفات الهوية والكشوف تدريبية وغير صالحة للاستخدام الرسمي.
