# Fictional training signatures

`demo-signatures.js` contains six original SVG pen marks made for this component. They are not traced from a real person's signature and do not identify or authenticate a signer. The ledger randomly selects different marks for the issuer, manager, and fictional stamp on each permit.

The paths are reusable offline vector assets; no image-generation service, font, download, or third-party attribution is required at runtime.
