# Saudi emblem source

Original asset: `saudi-emblem.svg`.

Source supplied by the user: [Wikimedia Commons — Emblem of Saudi Arabia (2).svg](https://commons.wikimedia.org/wiki/File:Emblem_of_Saudi_Arabia_%282%29.svg).

Original SVG download: https://upload.wikimedia.org/wikipedia/commons/4/45/Emblem_of_Saudi_Arabia_%282%29.svg

The Commons file page credits Zyido and lists the work as public domain. The downloaded SVG is retained unchanged. Its path geometry and #006C35 fill are embedded in the card HTML; only placement, scale, and the background copy's opacity are adjusted. The running application makes no requests to Wikimedia.

# Integrated Water Company training logo

`integrated-water-company-logo.png` is the fictional company artwork supplied by the user in `resources/integrated-water-company-logo-with-text.png`, retained unchanged. `integrated-water-company-logo-small.png` is a 600-pixel-wide optimized copy; `ledger-assets.js` embeds that copy locally for the standalone HTML. The lettering and right-side icon are preserved. The ledger uses the full-color logo in the header and a blue-ink version in the fictional stamp.
